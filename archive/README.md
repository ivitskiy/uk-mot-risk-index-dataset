# Superseded evidence capsules

v1 and v2 are superseded because they counted repeated records in the DVSA 2024 source files. v3 carries the same family and defect-group numbers as the current v4 in the parent directory; v4 adds outside sources, mileage within age groups and model years. These files are retained for historical citations.
